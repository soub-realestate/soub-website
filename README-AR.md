تم اعتماد ملف «صوب العقارية(2).html» الذي أرسلته مؤخرًا بدل الإصدار السابق. الواجهة الرئيسية أصبحت بدرجات البيج الرملي، مع الألوان الخضراء للنصوص والأزرار، وخلفيات جديدة للخدمات والتواصل. تصميم النسخة السابقة وإمكانات لوحة الإدارة محفوظة.

# موقع صوب العقارية — نسخة قابلة للإدارة

هذه نسخة معدلة من ملف HTML الذي أرسلته، وتحافظ على التصميم الأساسي مع إضافة إدارة المحتوى.

## ما يمكن تعديله من الجوال
- اسم ووصف الموقع، عنوان الواجهة، نصوص من نحن.
- إضافة/حذف/ترتيب خانات القيم والخدمات.
- إضافة/حذف أقسام إضافية، ولكل قسم خاناته وصوره.
- أرقام الاتصال وواتساب والبريد، وخيارات نموذج الطلب.
- تغيير صورة الواجهة ورفع صور الخانات.
- إظهار/إخفاء أقسام من نحن والخدمات والتواصل.

## تنبيه مهم قبل النشر
تم ترك حقول واتساب والاتصال والبريد **فارغة** داخل data/site.json لأنك لم تؤكد أن بيانات التواصل المكتوبة في ملف HTML الحالي تخص موقعك النهائي. بعد ضبط الرقم من لوحة الإدارة يتم تفعيل الروابط. بيانات الترخيص في أسفل الملف من المصدر الذي أرسلته ولم نتحقق منها؛ راجعها قبل النشر.

## طريقة النشر والإدارة (مرة واحدة)
1. أنشئ حساب GitHub خاصًا بك: https://github.com/signup
2. أنشئ مستودعًا جديدًا مثل `soub-website`، ويُفضّل Private، وارفع **جميع الملفات والمجلدات** الموجودة في هذا الأرشيف إلى جذر المستودع (تأكد من وجود الملف المخفي `.pages.yml` في الجذر). اختر الفرع `main`.
3. في Cloudflare: Workers & Pages → Create application → Pages → Connect to Git → GitHub → اختر المستودع.
4. إعدادات البناء للموقع الثابت: **Framework preset: None**، **Build command: اتركه فارغًا**، **Build output directory: /** أو `.` وفق ما تقبله شاشة Cloudflare. ملفات الموقع موجودة في جذر المستودع.
5. افتح https://app.pagescms.org وسجّل الدخول بنفس GitHub ثم فوّض التطبيق للوصول إلى المستودع الذي تملكه.
6. افتح مشروع `soub-website` وستظهر شاشة عربية الحقول باسم «إدارة موقع صوب العقارية» بفضل الملف `.pages.yml`.
7. عدّل قيمة أو أضف خانة ثم اضغط حفظ. تنتقل التغييرات إلى GitHub ويعيد Cloudflare Pages نشر الموقع تلقائيًا عند اكتمال البناء (قد يستغرق قليلًا).
8. عنوان /admin/ في الموقع عبارة عن صفحة انتقال إلى نظام Pages CMS؛ ليس هناك كلمة مرور محلية غير آمنة أو لوحة وهمية مفتوحة للزوار. التحكم الفعلي عبر حساب GitHub المصرح له فقط.

## بخصوص مشروع Cloudflare السابق
إذا كنت قد أنشأت مشروعًا بطريقة **Direct Upload / Drag and drop** فلا يمكن تحويل نفس المشروع إلى **Git integration** مباشرة؛ أنشئ مشروع Pages جديدًا مرتبطًا بمستودع GitHub. بعد التأكد من نشر النسخة الجديدة يمكن توجيه النطاق إليها.

## تعديل المحتوى يدويًا
الملف `data/site.json` يحمل النصوص والأقسام. الملف `app.js` يقرأها ويعرضها داخل نفس التصميم. `index.html` هو تصميم HTML الأصلي مع أقل تعديل لازم. لا تغير شكل JSON إن كنت تستخدم التعديل اليدوي.
